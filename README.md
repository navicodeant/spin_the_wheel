# 🎡 Spin the Wheel - React JS Game

Welcome to **Spin the Wheel**, a fun and interactive game built using **React.js**, with the logic, UI, and structure designed with the help of **AI tools** 🤖.

---

## ✨ Features

- 🧩 **Custom Segments** – Easily configurable wheel sections.
- 🌀 **Smooth Animation** – CSS-powered spinning motion.
- 🔮 **Random Outcome Logic** – Fair and fun spin results.
- 🎊 **Win Effects** – Optional confetti, sound, or message popups.
- 📱 **Responsive Design** – Works on desktop, tablet, and mobile.

---

## 🧠 Built With AI

Crafted using the power of:
- 🤖 **ChatGPT** – Logic, bug fixing, and design suggestions
- 🧠 **GitHub Copilot** – Intelligent code generation

These tools were used for:
- Generating React component structure
- Crafting reusable logic for spinning
- Styling assistance and animations
